# Student Management System

A console-based Student Management System developed using Java, JDBC, MySQL, and Maven.

## Features

- Add Student
- View All Students
- Search Student by ID
- Update Student
- Delete Student
- Console-based menu interface

## Technologies Used

- Java 21
- JDBC
- MySQL
- Maven
